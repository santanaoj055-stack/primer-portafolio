# Mi Primer Portafolio

Sitio web personal de portafolio desarrollado como practica de control de
versiones con Git y GitHub. Presenta una estructura sencilla con informacion
sobre mi, los proyectos realizados y los datos de contacto.

## Descripcion

La pagina es un sitio estatico construido con HTML5 y CSS. Incluye un
encabezado con el nombre del autor, secciones de "Sobre mi", "Proyectos" y
"Contacto", y un pie de pagina. Los estilos usan tipografia Arial, colores
neutros y secciones presentadas como tarjetas.

## Archivos

- `index.html`: estructura del sitio (header, secciones y footer).
- `style.css`: hoja de estilos vinculada desde el `<head>` de `index.html`.
- `README.md`: este archivo, con la descripcion del proyecto.

## Como verla

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en cualquier navegador web.
3. Opcionalmente, usa una extension como Live Server para recargar los cambios
   automaticamente.

Tambien puedes verla publicada en GitHub Pages si se habilita desde la
configuracion del repositorio.
